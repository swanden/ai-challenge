# CLI: команды и флаги

Точка входа — `go run ./week-7/task-32`. Без флагов запускается интерактивный REPL с
памятью, профилем, инвариантами и MCP-инструментами.

## Демонстрационные команды (по одной на день)

Каждая печатает самодокументируемый отчёт: что проверяется, что получилось, итоговый
чеклист задания.

| Флаг | Что показывает |
|---|---|
| `-report` | память (3 слоя) и профили |
| `-eval` | 10 контрольных вопросов с RAG и без |
| `-eval23` | матрица 2×2: {код, русский} × {baseline, improved retrieval} |
| `-eval24` | grounded-ответы с источниками, цитатами и режимом «не знаю» |
| `-chat25` | мини-чат: RAG + память задачи |
| `-local26` | локальная LLM: три запроса разной сложности |
| `-agent27` | агентские флоу на локальном бэкенде (мини-чат + рой) |
| `-compare28` | сравнение локаль ↔ облако: качество, скорость, стабильность |
| `-optimize29` | оптимизация под кейс: пресеты ДО/ПОСЛЕ |
| `-serve30-demo` | приватный OpenAI-совместимый сервис + все проверки |
| `-help31` | **ассистент разработчика: /help по документации проекта + живой git-контекст** |

## Интерактивные режимы

| Флаг | Режим |
|---|---|
| (без флагов) | REPL: агент с памятью, профилем, инвариантами, MCP |
| `-chat` | мини-чат по русскому корпусу (RAG + память задачи) |
| `-local` | чат напрямую с локальной моделью, без облака |
| `-watch N` | режим 24/7: фоновый сбор + сводка каждые N секунд |
| `-serve30` | поднять HTTP-сервис на локальной модели до Ctrl+C |

## Команды REPL

| Команда | Что делает |
|---|---|
| `/help <вопрос>` | **ассистент разработчика: ответ по документации проекта + живой git-контекст** |
| `/mem` | показать содержимое памяти |
| `/reset-task` | очистить рабочую память |
| `/track <город> [сек]` | поставить город на фоновый сбор погоды |
| `/untrack <город>`, `/untrack-all` | снять с отслеживания |
| `/summary [город]` | сводка по накопленным замерам |
| `/watch <сек>` | включить периодическую сводку |
| `exit` | сохранить память и выйти |

## Ключевые флаги

### Генерация

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `-backend` | `cloud` | `cloud` \| `local` — бэкенд текстовых флоу (шов `Completer`) |
| `-local-model` | `qwen2.5:7b` | генерирующая модель в Ollama |
| `-max-tokens` | `4096` | лимит токенов ответа |
| `-profile` | `senior-go` | активный профиль (`profiles/<id>.md`) |

`-backend local` меняет не только источник генерации. Он ещё **выключает облачный
LLM-реранк** (иначе флоу не был бы полностью локальным) и, как следствие, **переводит
порог «не знаю» в косинусную шкалу** (0.35 вместо 3.0). Без этого перевода агент уходил
бы в «не знаю» на каждом ходу — score и порог оказались бы в разных шкалах.

### RAG

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `-rag` | `false` | отвечать с RAG-контекстом |
| `-index` | `ragindex/index-structural.json` | индекс корпуса кода |
| `-index-ru` | `ragindex-ru/index-structural.json` | индекс русских лекций |
| `-index-docs` | `ragindex-docs/index-structural.json` | **индекс документации проекта (для `/help`)** |
| `-rag-k` | `4` | сколько чанков подмешать в контекст |
| `-topn` | `10` | сколько кандидатов достаёт bi-encoder |
| `-rerank` | `true` | второй проход: rewrite + порог + MMR + LLM-реранк |
| `-rewrite` | `true` | переписывать запрос перед поиском |
| `-mmr` | `0.7` | λ диверсификации MMR (1 = выключено) |
| `-threshold` | `0.0` | порог отсечения по косинусу (0 = выключено) |
| `-embed-model` | `nomic-embed-text` | модель эмбеддингов (обязана совпадать с моделью индекса) |
| `-rerank-model` | `claude-haiku-4-5-20251001` | модель для rewrite/реранка. Прежний дефолт `claude-3-5-haiku-latest` **ретайрнут** → API отдаёт 404 |
| `-ollama` | `http://localhost:11434` | базовый URL Ollama |

## Сборка индексов

```bash
# индекс документации проекта (корпус /help)
go run ./week-7/task-32/ragindex \
  -out week-7/task-32/ragindex-docs \
  -ext .md,.go

# то же, но без Ollama — только chunking и сравнение стратегий
go run ./week-7/task-32/ragindex -dry-run
```

Флаги индексатора: `-docs` (каталог-корпус), `-ext`, `-out`, `-chunk-size`, `-overlap`,
`-max-embed-chars` (потолок длины текста для эмбеддинга, по умолчанию 1800),
`-dry-run`, `-report`, `-query` (прогнать поиск после сборки).
